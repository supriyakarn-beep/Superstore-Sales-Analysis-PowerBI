Superstore Sales Analysis | SQL & Power BI

Project Overview

This project analyzes Superstore sales data using SQL and Power BI to identify business trends, evaluate profitability, and understand product and customer performance.

Tools & Technologies

- MySQL
- SQL
- Power BI Desktop
- Data Visualization
- Business Intelligence

Key Performance Indicators

- Total Sales
- Total Profit
- Total Quantity Sold
- Profit Margin
- Average Order Value

Dashboard Features

- Sales by Product Category
- Sales by Customer Segment
- Shipping Delay Analysis
- Interactive Year Filter
- Business Performance Overview

Key Business Insights

- Technology generated the highest profit among the three product categories.
- Furniture had a considerably lower profit margin than Technology and Office Supplies.
- The West region generated the highest sales and profit among the four regions.
- Higher discounts were associated with losses in the analyzed dataset.

Project Files

- "Superstore_Sales_Analysis.pbix" — Interactive Power BI dashboard.
- "SQL_Analysis.sql" — SQL queries used for sales analysis.
- "dashboard.png" — Dashboard preview.

How to Use

1. Download the ".pbix" file.
2. Open it in Microsoft Power BI Desktop.
3. Use the interactive visuals and filters to explore the results.
